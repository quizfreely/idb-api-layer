# Quizfreely IndexedDB API Layer

https://quizfreely.org/docs/idb-api-layer

[Codeberg](https://codeberg.org/quizfreely/idb-api-layer) · [GitHub](https://github.com/quizfreely/idb-api-layer)

Quizfreely's IDB API Layer lets Quizfreely's web-app's frontend code interact with IndexedDB similar to how Quizfreely's backend API ([Codeberg](https://codeberg.org/quizfreely/api), [GitHub](https://github.com/quizfreely/api)) lets frontend code interact with Quizfreely's database on our server.

It's a client-side JavaScript API for storing & interacting with users' local studysets & data.

The API Layer uses IndexedDB with Dexie.js.
